# 1/2 Room Website 🏫

## ภาพรวมของโปรเจกต์ (Overview)

**1/2 Room Website** เป็นโปรเจกต์ที่สร้างขึ้นเพื่อเป็นศูนย์กลางความทรงจำของเพื่อนๆ ห้อง ม.1/2 โดยเฉพาะ เป็นพื้นที่ที่รวมรวบข้อมูลสมาชิก รูปภาพกิจกรรม และเรื่องราวสนุกๆ ที่เกิดขึ้นภายในห้อง เพื่อให้ทุกคนสามารถกลับมาย้อนดูมิตรภาพดีๆ ได้เสมอผ่านหน้าจอเว็บไซต์

---

## ฟีเจอร์หลัก (Key Features)

* **Classmates Directory**: รายชื่อสมาชิกในห้อง ม.1/2 ที่ออกแบบมาให้อ่านง่ายและเข้าถึงได้รวดเร็ว
* **Memory Album**: แกลเลอรีรูปภาพรวบรวมโมเมนต์สำคัญ ไม่ว่าจะเป็นกิจกรรมในโรงเรียน หรือความเฮฮาในห้องเรียน
* **Space for Everyone**: พื้นที่ดิจิทัลที่เป็นตัวแทนของความเป็นหนึ่งเดียวของนักเรียนห้อง 1/2
* **Responsive Design**: รองรับการใช้งานจากทุกอุปกรณ์ เพื่อให้เพื่อนๆ เข้ามาดูผ่านมือถือได้สะดวกทุกที่ทุกเวลา

---

## เทคโนโลยีที่ใช้พัฒนา (Technologies Used)

| เทคโนโลยี | หน้าที่ในโปรเจกต์ |
| :--- | :--- |
| **Next.js & React** | ใช้เป็น Framework หลักในการสร้างโครงสร้างเว็บไซต์ที่ทันสมัยและรวดเร็ว |
| **Tailwind CSS** | จัดการเลย์เอาต์และดีไซน์ให้สวยงาม ดูสะอาดตา และมีความเป็นวัยรุ่น |
| **Vercel** | ระบบ Hosting ที่ใช้ Deploy เว็บไซต์ให้เพื่อนๆ เข้าใช้งานผ่านโดเมนจริง |
| **Custom DNS** | เชื่อมต่อผ่านโดเมนส่วนตัวที่ `room1-2.suphason.space` |

---

## ความท้าทายและสิ่งที่ได้เรียนรู้ (Challenges and Learnings)

ความท้าทายหลักของโปรเจกต์นี้คือการจัดการ Error ต่างๆ ที่เกิดขึ้นระหว่างการพัฒนา เช่น ปัญหาเรื่อง Hydration และการจัดการ Script Tag ซึ่งเป็นบทเรียนสำคัญที่ช่วยให้เข้าใจการทำงานของ Next.js ได้ลึกซึ้งยิ่งขึ้น นอกจากนี้ยังได้เรียนรู้เรื่องการจัดการโดเมนและ Subdomain เพื่อให้ได้ที่อยู่ที่จดจำง่ายสำหรับเพื่อนทุกคน

## ผลลัพธ์ (Outcome)

เว็บไซต์ห้อง ม.1/2 ที่เสร็จสมบูรณ์ ไม่ได้เป็นเพียงแค่การส่งงานโปรเจกต์เท่านั้น แต่เป็นเครื่องบันทึกความทรงจำแบบดิจิทัลที่จะคงอยู่ตลอดไป และเป็นก้าวสำคัญในการพัฒนาทักษะ Web Development ของผมให้ดียิ่งขึ้น
