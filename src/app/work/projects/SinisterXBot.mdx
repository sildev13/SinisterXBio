## ภาพรวมของโปรเจกต์ (Overview)

**SinisterX** เป็นบอท Discord แบบ **All In One** ที่ผมพัฒนาขึ้นเพื่อให้เซิร์ฟเวอร์เดียวสามารถใช้บอทตัวเดียวจบ ไม่ต้องเชิญบอทหลายตัวให้วุ่นวาย ครอบคลุมตั้งแต่งานดูแลสมาชิก ระบบความปลอดภัย ไปจนถึงความบันเทิงอย่างเพลงและเกม พร้อมกันนั้นผมยังทำเว็บ **SinisterX Docs** ขึ้นมาเป็นคู่มือการใช้งาน เพื่อให้แอดมินเซิร์ฟเวอร์เปิดอ่านคำสั่งทั้งหมดได้ง่ายๆ ผ่านเว็บ แทนที่จะต้องพิมพ์ `/help` ไล่ดูทีละอัน

## ฟีเจอร์หลักของบอท (Key Features)

- **Moderation & AutoMod**: คำสั่งจัดการสมาชิกครบชุด ทั้ง ban / kick / timeout / warn / clear พร้อมระบบ AutoMod ที่กันสแปม ลิงก์ และคำต้องห้ามแบบอัตโนมัติ โดยตั้งค่าคำเองได้
- **Security (Anti-Nuke)**: ระบบป้องกันการถล่มเซิร์ฟเวอร์ ช่วยรักษาเซิร์ฟเวอร์ไว้ได้แม้มีคนพยายามก่อกวน
- **Ticket & Giveaway**: ระบบเปิด Ticket สำหรับซัพพอร์ตสมาชิก และระบบจัดกิจกรรมแจกของ
- **Welcomer & Custom Roles**: ตั้งข้อความต้อนรับสมาชิกใหม่ และให้สมาชิกกำหนด role ของตัวเองได้
- **Music & Voice**: เล่นเพลงในห้องเสียงด้วยคำสั่ง play / queue / pause / resume / skip
- **Economy & Fun**: ระบบเศรษฐกิจในเซิร์ฟเวอร์ และคำสั่งสนุกๆ อย่าง `/iq` ไว้เล่นกับเพื่อน

## ฟีเจอร์ของเว็บ Docs (Documentation Site)

- **หน้า Commands แบบแบ่งหมวด**: จัดกลุ่มคำสั่งเป็นหมวดหมู่ชัดเจน พร้อมสารบัญด้านข้างที่กระโดดไปยังหัวข้อที่ต้องการได้ทันที
- **ระบบค้นหา**: กด `Ctrl + K` เพื่อค้นหาคำสั่งหรือหัวข้อในเอกสารได้ทันที
- **Dark Mode**: สลับธีมสว่าง/มืดได้ตามความชอบของผู้อ่าน
- **Responsive Design**: อ่านได้สบายทั้งบนคอมพิวเตอร์และมือถือ

## เทคโนโลยีที่ใช้ (Technologies Used)

- **Discord.js**: ใช้เขียนตัวบอทและจัดการ Event ต่างๆ ภายในเซิร์ฟเวอร์
- **React + Vite**: ใช้สร้างเว็บ Documentation ให้โหลดเร็วและพัฒนาได้คล่องตัว
- **Tailwind CSS**: จัดการหน้าตาเว็บให้เรียบร้อยและ Responsive
- **Vercel**: ใช้ Deploy เว็บ Docs ขึ้นโดเมนย่อยของตัวเอง

## ความท้าทายและสิ่งที่ได้เรียนรู้ (Challenges and Learnings)

ความท้าทายหลักคือการรวมฟีเจอร์จำนวนมากไว้ในบอทตัวเดียวโดยที่โค้ดยังอ่านง่ายและไม่พันกัน ผมจึงต้องเรียนรู้เรื่องการแยกไฟล์คำสั่งเป็นหมวดหมู่ และจัดการ Permission ให้รัดกุม โดยเฉพาะคำสั่งที่มีผลกระทบสูงซึ่งต้องจำกัดให้เฉพาะแอดมินเท่านั้น อีกเรื่องที่ได้เรียนรู้คือการเขียนเอกสาร เพราะบอทที่มีคำสั่งเยอะแต่ไม่มีคู่มือ สุดท้ายก็ไม่มีใครใช้ได้เต็มประสิทธิภาพ

## ผลลัพธ์ (Outcome)

ตอนนี้ **SinisterX** ทำงานอยู่ในเซิร์ฟเวอร์ Discord ของทีม โดยมีเว็บ Docs เป็นคู่มือกลางให้แอดมินและสมาชิกเปิดดูได้ตลอดเวลา โปรเจกต์นี้ทำให้ผมได้ฝึกทั้งฝั่ง Backend ของบอท และฝั่ง Frontend ของเว็บไปพร้อมกัน
